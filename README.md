# 咖啡比赛双语字幕

一个可分享的 Codex skill：使用选手原稿和剪映导出的现场原声 SRT，校正比赛展演的中英双语字幕，并沿用既有断句与标点偏好。

## 工作方式

1. 提供选手原稿（英文或中英双语）和剪映导出的现场原声 SRT。
2. AI 对照原稿校正识别错误、整理本场术语，列出现场 SRT 与原稿的说法出入。
3. 用户核对措辞、增减、顺序、配方和数字等差异。未确认的部分保留为工作稿，不擅自定稿。
4. 按已确认的选择，以及上次的断句、标点和双语布局修正字幕。
5. 检查 SRT 结构、关键内容、时间与中英同步，输出可导入剪映或达芬奇的 SRT。
6. 用户返回人工修正版后，对比学习可复用习惯；新场次的人名和配方独立保存。

只有稿件和 SRT 时，不能把识别差异直接当作选手确实说错，也不能声称完成了听证。可另外提供比赛音视频核对发言和时间。

## 安装

可以将本仓库链接发给 Codex，并说：

> 请将这个仓库中的 coffee-competition-subtitles skill 安装到我的个人 skills 目录。

也可下载仓库 ZIP，将解压后的文件夹改名为 `coffee-competition-subtitles`，放到 `~/.agents/skills/`，确保结构为：

```text
~/.agents/skills/coffee-competition-subtitles/
├── SKILL.md
├── agents/openai.yaml
└── references/user-preferences.md
```

Codex 通常会自动发现新 skill；若没有出现，重启 Codex。

## 使用

安装后输入：

> 使用 $coffee-competition-subtitles。这是选手原稿和剪映现场原声 SRT，请先让我核对与原稿说法有出入的地方，再按原来的断句风格制作双语字幕。

然后附上两份素材。有历史人工修正版时一并提供，可更精确复刻断句和时长习惯。

## 输出与反馈

- `assistant/*_待核对.srt`：仍有说法差异等待用户决定的工作稿。
- `reports/原稿与现场差异待核对.md`：带时间定位、原稿、SRT 与建议的核对清单。
- `reports/差异确认记录.md`：用户选择及落实依据。
- `assistant/*_bilingual_v1.srt`：差异处理完成并经过检查的字幕。
- `gold/corrected.srt`：用户后续返回的人工修正版。

`references/user-preferences.md` 内含作者已确认的字幕偏好，例如保留英文撇号、减少普通句读标点、英文在上中文在下。其他使用者可明确更改规则或提供自己的人工样本。各人的本地学习结果不会自动同步到此仓库。

本仓库包含工作流与偏好说明，不包含原始比赛视频、选手完整稿件、历史 SRT 或账号凭据。它不会训练模型；“学习”指更新可复用偏好和任务报告。
