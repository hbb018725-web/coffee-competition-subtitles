# 用户的比赛字幕偏好

来源：之前咖啡比赛双语 SRT 的校正工作流。新比赛的明确要求和用户人工样本优先于这些默认值。

## 本次明确更新（2026-10-25）

- 默认输入是选手原稿和剪映导出的现场原声 SRT；AI 根据原稿校正识别错误。
- 现场 SRT 与原稿说法有出入时，必须先与用户核对，不能自行选用原稿或现场版本。
- 核对范围包含措辞、增减和顺序，不仅是术语与数字；没有音频证据时不能把 SRT 差异断言为真实临场改说。
- 按上次的断句、标点及字幕布局继续修正；用户没有回复争议项前，只推进无争议部分。
- 来源：用户在本次对话中明确更新工作流。

## 已有偏好

- 用剪映初稿或音频作为起点，修正识别错误、语义不顺、断句与时间，不只做稿件文本替换。
- 英文保留缩写与所有格的撇号，例如 `I'm`、`today's`、`Saturn's`。
- 比赛字幕沿用之前的无普通句读标点版本作为起点；保留小数点、撇号、单位及术语必要字符。新样本或本场要求另有标点风格时随之调整。
- 最终 SRT 不带批注、校准标记或解释文字。
- 双语逐条对应：英文在上、中文在下。中文措辞参考双语稿件，不能为了字面一致而漂移。
- 合并难以独立理解的碎片，长句按语义拆分；以同步和可读性判断，不按固定字数硬切。
- 人工修正版是本场金标准，保留其中的时间和表达，再对比学习。
- 工作闭环：AI 初稿 → 用户人工矫正 → 对比归类 → 更新可复用规则 → 下一场应用。

## 不跨比赛沿用的内容

上一场的人名、饮品名、主题、原料、风味、剂量与单位数值，只能作历史示例。新场次必须根据新素材重新建立术语表。

## 后续更新

每条新增长期偏好附简短来源说明，例如比赛任务名、用户明确指令或人工样本中的重复模式。本场的一次性修正留在任务报告，不写成全局规则。
